# ИНФОРМАЦИОННАЯ СИСТЕМА АВТОМАТИЗАЦИИ ETL КОНВЕЙЕРА ДЛЯ ПОДДЕРЖКИ ПРИНЯТИЯ РЕШЕНИЙ
Система предназначена для ежедневной загрузки, трансформации и предоставления актуальных бизнес-данных в виде витрин и детального слоя.
## Особенности
- Минимальная ручная вовлеченность пользователей
- Выгрузка данных из источников
- Трансформация и загрузка данных в 3НФ
- Выгрузка данных в витрины
- Процессы в формате DAG
## Предустановка и запуск
Перед запуском программы необходимо удостовериться в полном функционировании Greenplum DB и Apache Airflow на узлах сервера
Затем следует поместить файлы airflow_*.py совместно с директорией sql в директорию (/opt/airflow/dags) на рабочей машине Airflow и запустить соответствующие проекты с помощью консоли или с помощью веб-интерфейса
В случае консольного варианта запуска:
Найти идентификатор вашего DAG
```bash
airflow dags list
```
В случае, если ваш DAG имеет статус 'pause', то выполнить:
```bash
airflow dags unpause <dag_id>
```
иначе
```bash
airflow dags trigger <dag_id>
```
В случае интерфейсного варианта:
1) Разблокируйте DAG: По умолчанию новые DAG-и часто загружаются в состоянии "Paused" (на паузе). Найдите свой DAG в списке и переключите тумблер слева в положение On
2) Запуск: В правой части строки DAG-а найдите иконку "Play"
## Итоги
Процессы будут автоматически запускаться ежедневно в 00:00
Отслеживаение выполнения процессов доступно с помощью веб-интерфейса
Ежедневное обновление витрин
